# Meet Base 44 React Project

This is a React project set up to facilitate copying and working with code from the Meet Base 44 website.

## Project Structure

```

│   ├── pages
│   │   └── Home.tsx
│   ├── hooks
│   │   └── useFetch.ts
│   ├── styles
│   │   └── globals.css

├── tsconfig.json

├── .gitignore
└── README.md
```

## Getting Started

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd meet-base44-react
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the application:**
   ```
   npm run dev
   ```

## Features

- Custom hooks for data fetching
- Modular components for better maintainability
- Global styles for consistent design
- TypeScript for type safety
